  <a href="https://skillicons.dev">

### Frontend

- **Next.js**: 高度なレンダリング（SSR/ISR）を可能にする React フレームワーク
- **Vite**: 高速なビルドと開発体験を提供する次世代フロントエンドツール
- **Tailwind CSS**: ユーティリティ優先の CSS フレームワークで迅速な UI 構築
- **shadcn/ui**: カスタマイズ性とアクセシビリティに優れた UI コンポーネント集
- **TanStack Router**: 型安全で高度なルーティングを可能にするライブラリ
- **Vite Plugin PWA**: Vite プロジェクトに PWA 機能（オフライン対応等）を簡単導入
- **Astro**: 高速なコンテンツ配信に特化したモダンなアイランドアーキテクチャ

### Backend

- **Bun**: 高速な JavaScript 実行環境、パッケージマネージャー、テストランナー
- **Hono**: エッジ環境でも動作する軽量・爆速の Web フレームワーク
- **TypeScript**: 型定義により堅牢なコード開発を可能にする JS 拡張言語
- **Better Auth**: 現代的な Web アプリ向けの柔軟で安全な認証ライブラリ
- **Zod**: スキーマ定義と型推論を同時に行うバリデーションライブラリ

### Database

- **PostgreSQL**: 高い信頼性と拡張性を誇るオープンソースの RDBMS
